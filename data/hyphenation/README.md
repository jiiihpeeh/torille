# Finnish hyphenation patterns

`hyph-fi-x-school.tex` is the MIT-licensed Finnish school hyphenation
pattern set from the `hyph-utf8` project:

- language: Finnish, school hyphenation (`fi-x-school`)
- version: 1.0, 2021-03-21
- authors: Teemu Likonen and Arthur Rosendahl
- licence: MIT (see `LICENSE` in this directory)
- upstream: <https://github.com/hyphenation/hyph-utf8>

The file is reproduced unmodified. It is data, not engine source: it is
covered by its own MIT notice and is not relicensed by torille's
`MIT OR Apache-2.0` terms.

The engine's Finnish typographic policy filters and ranks the pattern
candidates, and the morphology layer supplies compound boundaries. See
`PLAN_HYPHENATION.md` and `docs/hyphenation.md`.
